# Azimuth Map

Односторінковий вебзастосунок для побудови секторів азимуту від базової станції (БС) на мапі.
Просто відкрийте `index.html` у браузері або розмістіть на GitHub Pages — збірка не потрібна.

## Можливості

- **Вибір точки БС** — тап по мапі, пошук, геолокація або тап по вже існуючій БС; маркер можна перетягувати.
- **Сектор** — азимут, дальність (10 м – 50 км) і ширина променя (0° = лише лінія, 360° = коло) з живим попереднім переглядом.
- **Список секторів** — перехід до сектора, копіювання координат кінцевої точки, видалення з можливістю «Повернути».
- **Пошук** — адреси через OpenStreetMap Nominatim та координати у форматах
  `50.4501, 30.5234`, `50,4501 30,5234`, `48°44'14"N 37°35'13"E`, `N48 44 14 E37 35 13`, `48°44.233' 37°35.221'`.
- **Шари** — OpenStreetMap, Візіком, супутник Esri.
- **Експорт / імпорт** у GeoJSON.
- **Автозбереження** секторів, налаштувань і позиції мапи в `localStorage`.
- Світла/темна тема, адаптація під телефон і ПК, приховування інтерфейсу.

> Тайли Візіком без власного API-ключа можуть показувати попередження про обмеження використання,
> тому за замовчуванням використовується OpenStreetMap.
