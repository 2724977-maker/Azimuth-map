# Azimuth Map

Вебзастосунок для побудови секторів азимуту від базової станції (БС) на мапі.
Увесь застосунок — один файл `index.html` (бібліотека Leaflet вбудована), тож його можна
відкрити в будь-якому браузері або розмістити на GitHub Pages.

> Мапа завантажує тайли з інтернету, тому відкривайте сторінку в браузері (Chrome, Safari).
> Вбудовані переглядачі файлів (наприклад, у застосунку Claude) блокують мережу, і мапа там не з’явиться.

## Можливості

- **Компас** — поверніть стрілку пальцем, щоб задати азимут; точне значення можна ввести вручну.
- **Сектор** — дальність (10 м – 50 км) і ширина променя (0° = лише лінія, 360° = коло), швидкі пресети, живий попередній перегляд на мапі.
- **Вибір БС** — тап по мапі, пошук, геолокація або тап по вже наявній станції; маркер можна перетягувати.
- **Список секторів** — перехід до сектора, копіювання координат кінцевої точки, видалення з кнопкою «Повернути».
- **Пошук** — адреси (OpenStreetMap Nominatim) та координати у форматах
  `50.4501, 30.5234`, `50,4501 30,5234`, `48°44'14"N 37°35'13"E`, `N48 44 14 E37 35 13`, `48°44.233' 37°35.221'`.
- **Шари** — OpenStreetMap, Esri Вулиці, Візіком, супутник; якщо джерело недоступне, шар перемикається автоматично.
- **Експорт / імпорт** у GeoJSON, автозбереження в браузері, світла й темна тема, компактний режим панелі.

## Встановлення на телефон

Сайт: **https://2724977-maker.github.io/Azimuth-map/**

- **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
- **iPhone (Safari):** кнопка «Поділитися» → «На екран „Додому“».

Після першого відкриття застосунок запускається й без інтернету, а переглянуті ділянки мапи
зберігаються на пристрої до 7 днів (до 3000 тайлів). Пошук адрес потребує з’єднання.

## Мапа Візіком

Visicom віддає тайли без напису «Порушені умови чи досягнуті обмеження використання» лише з API-ключем.

1. Зареєструйтеся на [api.visicom.ua](https://api.visicom.ua/accounts/forms?action=register_form) і отримайте ключ Visicom Tiles.
2. Якщо кабінет дозволяє обмежити ключ доменами, додайте домен сайту (наприклад, `2724977-maker.github.io`).
3. У застосунку: кнопка шарів → «Ключ Visicom» → вставте ключ → «Зберегти». Ключ зберігається на пристрої.

Щоб ключ працював для всіх відвідувачів, впишіть його в `VISICOM_KEY` у `src/index.template.html` і зберіть `index.html`.

## Розробка

Редагуйте `src/index.template.html` і `src/sw.template.js`, потім зберіть `index.html` і `sw.js`:

```sh
python3 tools/build.py
```

Іконки перемальовує `python3 tools/icons.py` (потрібен Pillow). Скрипт збирання вбудовує `vendor/leaflet.js` і `vendor/leaflet.css` (Leaflet 1.9.4, ліцензія BSD-2-Clause — `vendor/LEAFLET-LICENSE`).
