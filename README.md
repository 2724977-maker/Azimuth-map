# Azimuth Map

Вебзастосунок для побудови секторів азимуту від базової станції (БС) на мапі.
Увесь застосунок — один файл `index.html` (бібліотека Leaflet вбудована), тож його можна
відкрити в будь-якому браузері або розмістити на GitHub Pages.

> Мапа завантажує тайли з інтернету, тому відкривайте сторінку в браузері (Chrome, Safari).
> Вбудовані переглядачі файлів (наприклад, у застосунку Claude) блокують мережу, і мапа там не з’явиться.

## Можливості

- **Компас** — поверніть стрілку пальцем, щоб задати азимут; точне значення можна ввести вручну.
- **Сектор** — дальність (10 м – 50 км) і ширина променя (0° = лише лінія, 360° = коло), швидкі пресети, живий попередній перегляд на мапі.
- **Вибір БС** — тап по мапі, пошук, геолокація або тап по вже наявній станції; маркер можна перетягувати.
- **Список секторів** — перехід до сектора, копіювання координат кінцевої точки, видалення з кнопкою «Повернути».
- **Пошук** — адреси (OpenStreetMap Nominatim) та координати у форматах
  `50.4501, 30.5234`, `50,4501 30,5234`, `48°44'14"N 37°35'13"E`, `N48 44 14 E37 35 13`, `48°44.233' 37°35.221'`.
- **Шари** — OpenStreetMap, Esri Вулиці, Візіком, супутник; якщо джерело недоступне, шар перемикається автоматично.
- **Експорт / імпорт** у GeoJSON, автозбереження в браузері, світла й темна тема, компактний режим панелі.

## Розробка

Редагуйте `src/index.template.html`, потім зберіть `index.html`:

```sh
python3 tools/build.py
```

Скрипт вбудовує `vendor/leaflet.js` і `vendor/leaflet.css` (Leaflet 1.9.4, ліцензія BSD-2-Clause — `vendor/LEAFLET-LICENSE`).
